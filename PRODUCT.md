# Frame It Up

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Atreya and photographers preparing edited photographs for Instagram on desktop and phones.

## Product Purpose

Frame complete photographs and make landscapes readable as two or three continuous carousel slides preceded by a full framed overview. Automatically propose each photo's layout, with per-photo overrides.

## Capabilities and Constraints

Retain the existing static, local-processing application, four frame styles, metadata footers and individual and ZIP downloads. Default to full-resolution PNG without lossy compression, automatic downscaling, filters, sharpening, or upscaling. Offer an explicit maximum-quality sRGB Instagram JPEG copy. A carousel uses a common outer ratio; mixed native Instagram support varies and needs account verification. No backend, sign-in, direct publishing, or performance controls in the primary workflow.

## Brand Commitments

Keep the Frame It Up name. The latest user reference pins one cream (#eae7dc), sand (#d8c3a5), gray (#8e8d8a) and coral (#e98074/#e85a4f) visual system, with darker functional text/accent variants for legibility. No theme toggle. Source Serif 4 anchors the wordmark; Source Sans 3 serves the editor. Keep copy functional and minimal, exactly one Add photos action, no preloaded photos or demonstration language. Auto format coordinates supported dimensions and automatic splits, with explicit resizing while retaining the encoding choice. Full photo precedes split parts. Four styles: White, Black, Color, Film. Film keeps only the 35mm label, optional white/black mat and width control; no frame counters or barcodes. Each photo retains its frame and split settings; canvas and export format are explicitly shared across the batch.

## Product Principles

- Preserve source detail and make export transformations explicit.
- Let the photograph lead the workspace.
- Keep continuous slide boundaries mathematically consistent.
- Handle performance internally rather than asking the photographer to tune it.

## Open Decisions

Actual Instagram account support for Mixed orientation, hosting configuration, and support beyond edited SDR sRGB JPEG/PNG need verification. The initial browser workflow does not claim archival RAW/HDR preservation.
