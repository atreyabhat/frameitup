# Font sources

All fonts are self-hosted; SIL Open Font Licenses are included beside the font files.

Metadata typefaces added November 15, 2026, from the Google Fonts repository:

- DM Mono Regular: https://github.com/google/fonts/tree/main/ofl/dmmono
- Space Mono Regular: https://github.com/google/fonts/tree/main/ofl/spacemono
- Courier Prime Regular: https://github.com/google/fonts/tree/main/ofl/courierprime
- Barlow Condensed Regular: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- Source Serif 4 uses the existing locally hosted variable font and sourceserif4-OFL.txt.
